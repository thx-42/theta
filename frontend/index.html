features

Petit dehors, costaud dedans

Tout ce qui est ci-dessous vient du README — rien d'inventé, que du vérifiable.

🖥️

TUI + daemon qui ne dort jamais

Client plein écran + daemon en arrière-plan (~/.theta/theta.sock). Ferme ton terminal : rien ne s'arrête. Plusieurs terminaux peuvent s'attacher à la même session, en direct.

🪶

Sobre en tokens

Relecture intelligente, chemins relatifs, prompt caching Anthropic, compaction auto à 80 % de la fenêtre. Chaque token compte — θ les compte pour toi.

📜

SOUL, agents & skills

SOUL.md s'applique à tous les agents. Build code, Plan planifie puis passe la main. Les skills en .md s'injectent avec $nom — ou tout seuls si auto.

🔌

MCP natif

Serveurs MCP stdio + HTTP dans settings.toml, tools mcp__serveur__tool, login OAuth 2.1 PKCE. /mcp te dit qui est connecté : ● ○ ✗.

🗂️

Onglets & arbre de conversation

Sessions en onglets (alt+n, spinner quand ça bosse, ● quand c'est prêt). Arbre append-only : bifurque, réédite avec e, ne perds jamais une idée.

🧰

Des tools qui taffent

bash compacté via rtk, task pour les subagents à contexte neuf, web_search / web_fetch, todo, handoff Plan → Build, ask quand il hésite.

installation

En route en 30 secondes

Le script demande : binaire pré-compilé (rapide) ou compilation depuis les sources.

curl -fsSL https://raw.githubusercontent.com/thx-42/theta/main/install.sh | bash
  • sha256 vérifié, installe dans ~/.local/bin (THETA_PREFIX pour changer).
  • Si ~/.local/bin n'est pas dans ton PATH : export PATH="$HOME/.local/bin:$PATH"
curl -fsSL https://raw.githubusercontent.com/thx-42/theta/main/install.sh | bash -s -- install --source
  • Nécessite cargo + git. Depuis un clone : ./install.sh install --source.
