---
name: design
description: Build distinctive, polished interfaces with a deliberate visual direction
---
Design and implement the requested interface, from a component to a complete page. Deliver working code in the project's existing stack.

Before editing, inspect nearby UI, styles, dependencies and any supplied references. Preserve the product's established design language unless a redesign is requested. Infer the audience and primary task from the brief; ask only when a missing decision would materially change the result.

Choose a visual direction specific to the subject. Briefly state the typography, palette, layout and one memorable visual idea, then build. Carry those choices through reusable tokens and components. Give the primary action and most important content clear priority.

Treat typography, spacing and alignment as the foundation. Use deliberate type sizes, readable line lengths and a consistent spacing rhythm. Let content determine layout; use cards, gradients, shadows and decorative effects only when they serve that direction. Avoid reproducing the same generic landing page for every brief. The user's references and preferences take precedence over stylistic defaults.

Use realistic, domain-specific copy and meaningful assets. Keep action labels precise and terminology consistent. Wire interactions to working behavior; identify missing integrations without inventing successful results. Handle loading, empty, error and success states where relevant.

Make layouts work on narrow and wide screens. Use semantic elements, accessible labels, keyboard navigation, visible focus, sufficient contrast and reduced-motion support. Keep animation purposeful.

Run the project's relevant checks. If preview tools are available, inspect the rendered interface at mobile and desktop sizes, exercise the main interaction and fix clipping, overflow, weak hierarchy and broken states. Report what was checked and any preview limitation honestly.
